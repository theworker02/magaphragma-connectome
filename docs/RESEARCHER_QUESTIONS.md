# Questions for original researchers

Do not send this file automatically. It is a technically specific, respectful preparation aid.

1. Is there a public, stable download for the complete FIB-SEM volume or only CATMAID-hosted visualization?
2. Which specimen(s), coordinate conventions, voxel origin, and transforms underlie the published lamina reconstruction?
3. Which head/CNS regions are fully acquired, and which are affected by acquisition or preparation artifacts?
4. Which neuron and synapse reconstructions are published, in review, or under active unpublished proofreading?
5. Are CATMAID exports, imagery tiles, skeletons, and synapse annotations available for download? Under which licenses and citation requirements?
6. Are additional WASPSYN annotations, source artifact hashes, and volume identifiers available outside the challenge portal?
7. Would provenance-preserving derived segments, proofreading corrections, or open tools be useful to contribute back, and in what format?
8. What known coordinate transforms, quality-control thresholds, or acquisition artifacts should downstream users preserve?
