## Introduction

*Megaphragma viggianii* is an unusually small parasitoid wasp with published early-visual-system reconstruction work. Vigilia provides infrastructure for auditable extension only where source microscopy, rights, provenance, and review justify it.

## Existing *Megaphragma* work

Chua et al. (2023) reconstructed the early visual system and lamina. Li et al. (2024) introduced WASPSYN for domain-adaptive synapse detection using regional FIB-SEM subvolumes. See `research/NOVELTY_AUDIT.md`.
