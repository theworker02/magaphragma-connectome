# Phase 6C-A independent-model audit

No independent pretrained neuronal-instance model was acquired for this bounded
experiment. The official SegNeuron model remains the only local neuronal
instance model, so its affinity postprocessors are recorded as shared ancestry,
not independent votes. The public Bootstrapper capsule advertises an 8-nm
FIB-SEM track and pretrained correctors, but its documented data workflow is a
separate multi-gigabyte capsule and no directly compatible local inference
checkpoint was acquired or evaluated. It is therefore `INDEPENDENT_MODEL_UNAVAILABLE`.

The raw-EM Gaussian-gradient boundary layer is a separate image-derived support
signal only. It is not a learned neuronal instance segmentation or biological
ground truth.
